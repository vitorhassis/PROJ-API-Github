## 🛠 Funcionalidades  

✔️ Buscar repositórios públicos de um usuário do GitHub  
✔️ Exibir nome, data de criação e linguagem predominante de cada repositório  
✔️ Interface dinâmica e responsiva  

---

## 🚀 Tecnologias utilizadas  

- ✅ **HTML5** - Estruturação da página  
- ✅ **CSS3** - Estilização e layout responsivo  
- ✅ **JavaScript** - Consumo da API e manipulação do DOM
